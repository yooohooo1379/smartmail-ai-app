# SmartMail AI App

SmartMail AI App is an open-source AI-powered email assistant designed to help users summarize emails, generate professional replies, and improve inbox productivity.

## Features

- AI-powered email summarization
- Smart reply generation
- Professional email drafting
- Clean and modern interface
- Open-source and customizable

## Tech Stack

- Next.js
- Tailwind CSS
- TypeScript
- AI API Integration

## Future Roadmap

- Gmail integration
- Multi-language support
- AI email categorization
- Browser extension
- Mobile app support

## Installation

bash npm install npm run dev 

## Usage

Paste an email into the app and generate:
- Summaries
- Smart replies
- Professional drafts
